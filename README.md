# PC Thermal and Noise Fault Investigation

Hardware test report by Josiah Francis (Aug to Sep 2026): diagnosing a throttling RTX 3070 desktop with HWiNFO sensor logs, changing one variable at a time.

Read it here: https://jozxo.github.io/pc-thermal-report/

- `index.html`: the report
- `charts/`: charts made from 13 logged gaming sessions
- `code/make_charts.py`: the script that made the charts (expects the HWiNFO CSV logs in a `logs/` folder)
